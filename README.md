# CorpBank 🏦

Sistema bancário interativo de terminal desenvolvido em Python.

## Funcionalidades

- Verificar saldo
- Realizar depósito
- Sacar dinheiro
- Transferir para outra conta
- Autenticação por senha com limite de 3 tentativas
- Limite de saque/transferência diário de R$ 5.000,00

## Como executar

Certifique-se de ter o Python instalado, depois rode:

```bash
python CorpBank.py
```

## Tecnologias

- Python 3
